## What is SnapFrame?

SnapFrame is a Chrome extension that turns boring browser screenshots into polished marketing assets with:

- 🖼️ **30+ Device Frames** — Browser, Mobile, Tablet, Desktop, Social Media
- 🎨 **9 Gradient Backgrounds** — Cotton Candy, Deep Sea, Lavender, and more
- 📋 **One-Click Export** — Copy to clipboard or download as PNG
- ✨ **Full Customization** — Padding, corner radius, shadows, and branding
